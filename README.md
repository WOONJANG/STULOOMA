# STULOOMA 0.1.0 Development Downloads

Windows executable ZIP is stored with Git LFS; the source ZIP is a regular Git file.

Extract the entire Windows ZIP and run STULOOMA-win32-x64/STULOOMA.exe. Keep resources and all bundled files together. This is an unsigned development preview. Native Windows execution is unverified.

Source commit: 6a6b0f0512aea24d52c469cd56a2d084ad448c6f.

The source, tests and documentation are on main. This independent distribution branch keeps executable downloads out of the source checkout. SHA256SUMS.txt describes actual downloaded ZIP bytes, not the LFS pointer.
