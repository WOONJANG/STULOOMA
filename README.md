# STULOOMA 0.2.0 개발판 다운로드

릴리스: https://github.com/WOONJANG/STULOOMA/releases/tag/v0.2.0-dev

Windows ZIP 전체를 풀고 STULOOMA-win32-x64/STULOOMA.exe를 실행합니다. resources 폴더를 포함한 파일 구성을 유지하세요.

Windows 실행 ZIP은 Git LFS 객체입니다. raw 호스트의 작은 포인터 대신 다음 주소로 다운로드하세요.
https://media.githubusercontent.com/media/WOONJANG/STULOOMA/downloads-v0.2.0-dev/STULOOMA-Windows-0.2.0.zip

소스: https://raw.githubusercontent.com/WOONJANG/STULOOMA/downloads-v0.2.0-dev/STULOOMA-source-0.2.0.zip

무결성은 SHA256SUMS.txt를 사용합니다. 서명되지 않은 개발판이며 Windows 실제 실행 검증은 남아 있습니다. Linux에서 자동 검사91개와 패키지 실행을 확인했습니다.
