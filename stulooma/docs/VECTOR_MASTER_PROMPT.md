# STULOOMA VECTOR STUDIO
## 기존 STULOOMA 프로그램에 전문 벡터 그래픽 편집 기능을 추가하기 위한 클린룸 개발 통합 마스터 프롬프트

**프로젝트:** STULOOMA
**추가 모듈:** Vector Studio
**참고 기능:** Adobe Illustrator 공식 사용 설명서에 공개된 벡터 디자인 기능
**구현 방식:** 클린룸 독립 구현
**기본 기술:** React + TypeScript + Vite + Electron
**핵심 표준:** SVG 2 / SVG 1.1 호환 하위 집합
**최종 목표:** 기존 STULOOMA의 3D 의류 디자인 기능과 완전히 연결된 전문 벡터 편집기

---

# 0. 최상위 실행 지시

당신은 세계 최고 수준의 소프트웨어 아키텍트, 컴퓨터 그래픽스 엔지니어, 벡터 그래픽 엔진 개발자, 의류 CAD 전문가, Electron 데스크톱 소프트웨어 개발자, TypeScript 개발자, UI/UX 전문가, 소프트웨어 테스트 엔지니어입니다.

현재 STULOOMA라는 3D 의류 디자인 및 목업 제작 프로그램이 일부 구현되어 있습니다.

**이번 작업은 STULOOMA를 처음부터 다시 개발하는 것이 아닙니다.**

이미 구현된 기능과 소스코드, 사용자 프로젝트, 데이터 구조, 3D 렌더링, UV 매핑, 의류 모델 라이브러리, 저장 기능을 유지하면서 전문 벡터 그래픽 편집 기능을 추가하는 것입니다.

Adobe Illustrator의 공식 도움말에 설명된 대표적인 벡터 편집 기능을 분석하여 독자적인 알고리즘과 코드로 구현하십시오.

이 기능은 STULOOMA 안에서 **Vector Studio**라는 작업 공간으로 제공하십시오.

최종 사용자는 다음 작업을 할 수 있어야 합니다.

1. 기존 STULOOMA 프로젝트를 엽니다.
2. Vector Studio 작업 공간으로 이동합니다.
3. 펜 도구로 자유롭게 벡터 패스를 그립니다.
4. 앵커포인트와 곡선 핸들을 수정합니다.
5. 도형을 합치거나 뺍니다.
6. 복합 패스를 만들어 구멍이 있는 글자와 도형을 만듭니다.
7. SVG 파일을 가져와서 가능한 요소를 벡터 객체로 편집합니다.
8. 텍스트를 작성하고 외곽선 벡터로 변환합니다.
9. 로고와 패턴을 제작합니다.
10. 완성한 디자인을 의류의 앞판, 뒷판, 소매 등에 적용합니다.
11. 3D 의류에 반영된 결과를 실시간 확인합니다.
12. 벡터 데이터를 수정 가능한 상태로 저장합니다.
13. SVG, PNG 등으로 내보냅니다.
14. 프로젝트를 다시 열어 벡터 디자인을 계속 편집합니다.

**가장 중요한 요구사항은 벡터 편집기와 기존 STULOOMA의 3D 디자인 엔진이 하나의 시스템으로 작동해야 한다는 것입니다.**

독립적인 데모 페이지를 만들지 마십시오.

# 3. 파일 형식 정책

이 요구사항은 개발을 시작하기 전에 확정하십시오.

## 3.1 Adobe AI 형식

`.ai` 파일은 Illustrator 전용 데이터가 포함될 수 있습니다.

PDF 호환 옵션을 사용해 저장한 일부 AI 파일에는 PDF로 해석할 수 있는 내용이 존재할 수 있지만, 이를 Illustrator 전체 편집 데이터의 공개 규격으로 취급해서는 안 됩니다.

따라서 초기 개발에서 다음을 금지하십시오.

- AI 파일 완전 지원 표시
- AI 원본 편집 데이터 전체 복원 보장
- AI 저장 기능을 원본과 동일하다고 주장
- 모든 AI 파일에 대해 완벽한 왕복 호환성 주장

사용자가 AI 파일을 직접 제공한 경우에도 허용된 공개 규격 범위에서만 처리하십시오.

PDF 호환 영역을 합법적이고 안전한 방식으로 읽을 수 있는 경우, 별도 변환 기능으로 취급하십시오.

## 3.2 기본 벡터 형식

**SVG를 기본 공개 벡터 교환 형식으로 사용하십시오.**

지원 대상:
- 경로
- 기본 도형
- 그룹
- 변형
- 칠
- 선
- 그라디언트
- 클리핑
- 마스킹
- 이미지
- 문자

SVG 규격 전체를 처음부터 구현한다고 주장하지 말고, 지원하는 요소와 속성의 범위를 문서화하십시오.

SVG 2의 구현 차이를 고려하고, SVG 1.1에서 널리 지원되는 기능을 우선하십시오.

## 3.3 저장 형식

- STULOOMA 프로젝트: `.stulooma`
- 벡터 교환: `.svg`
- 래스터 이미지: `.png`, `.jpg`, `.webp`
- 문서 출력: `.pdf` (실제 구현 후)
- 3D 출력: 기존 STULOOMA의 GLB/glTF 기능 유지

프로젝트 내부에는 자체 벡터 문서 모델을 저장하고 SVG는 가져오기·내보내기 형식으로 사용하십시오.

SVG가 모든 내부 편집 메타데이터를 보존한다고 가정하지 마십시오.

## 4.3 아키텍처

다음 독립 모듈을 설계하십시오.

**VectorDocument**

벡터 문서의 전체 상태와 구조 관리

**VectorSceneGraph**

도형, 경로, 그룹 및 레이어 계층 관리

**VectorGeometryEngine**

기하학 계산 및 패스 편집

**PathEditor**

앵커포인트와 곡선 핸들 조작

**ShapeBooleanEngine**

합집합, 차집합, 교집합, 대칭차 연산

**VectorRenderer**

2D 벡터 그래픽 표시

**VectorSelectionManager**

객체와 앵커포인트 선택

**VectorTextEngine**

문자 입력 및 외곽선 처리

**VectorExportEngine**

SVG 및 이미지 출력

**VectorToTextureAdapter**

벡터 디자인을 기존 STULOOMA Texture Composer에 연결

**VectorCommandAdapter**

기존 STULOOMA 명령 시스템과 연결

**VectorHistoryAdapter**

기존 Undo/Redo 시스템과 연결

기존 프로젝트의 모듈과 중복되는 기능은 가능한 경우 어댑터를 통해 재사용하십시오.

# 12. 도형 합치기 및 빼기

실무상 매우 중요한 기능입니다.

도형 간 Boolean 연산을 구현하십시오.

## 12.1 필수 기능

- 합집합: Union
- 앞면 빼기: Difference
- 교집합: Intersection
- 겹침 제외: XOR
- 도형 분할: Divide

## 12.2 구현 조건

겹치는 도형의 실제 경계를 계산하여 새로운 벡터 경로를 생성하십시오.

단순한 화면상 합성이나 클리핑 효과만으로 실제 Boolean 연산을 완료했다고 판단하지 마십시오.

곡선 경로를 처리할 수 있어야 합니다.

필요할 경우 허용 오차를 가진 기하학 계산 방식을 적용하십시오.

## 12.3 사용자 작업 예시

원형 두 개를 선택한 뒤 앞면 빼기를 실행하면 실제로 구멍이 있는 벡터 경로가 생성되어야 합니다.

도형을 합친 후에도 생성된 경로의 앵커포인트를 편집할 수 있어야 합니다.

## 12.4 비파괴 편집

가능하면 원본 도형을 유지하는 비파괴 Boolean Group을 지원하십시오.

사용자가 확정하는 경우 최종 경로로 변환할 수 있도록 하십시오.

- 회전

3D 모델 자체를 불필요하게 다시 로딩하지 마십시오.

기존 Texture Composer를 활용하십시오.

## 23.5 벡터 데이터 보존

편집 가능한 원본 벡터 문서와 3D 표시용 래스터 텍스처를 별도로 관리하십시오.

벡터 데이터를 수정하면 필요한 텍스처만 다시 생성하십시오.

## 23.6 벡터 및 래스터 혼합

- 선수명 텍스트
- 등번호

## 24.6 정합성

- 로고 위치가 임의로 이동
- 디자인 방향 반전
- 과도한 비율 왜곡
- 알파 채널 손실
- 잘못된 UV 영역 적용
- 텍스처 재생성 시 기존 레이어 삭제

# 32. 개발 실행 순서

아래 순서대로 개발하십시오.

각 단계가 끝날 때마다 비개발자도 이해할 수 있도록 3줄로 보고하십시오.

**완료:** 실제 구현된 기능
**검증:** 실행하거나 테스트로 확인한 결과
**다음:** 남은 문제 또는 다음 작업

## STEP 1. 기존 STULOOMA 분석

현재 프로젝트의 코드, 모듈, 데이터 구조를 검사하십시오.

기존 기능과 테스트 결과를 기록하십시오.

기존 프로그램을 임의로 초기화하지 마십시오.

## STEP 2. 공식 자료 조사

Adobe Illustrator 공식 도움말과 SVG 공개 규격을 확인하십시오.

주요 기능과 파일 형식을 정리하십시오.

`docs/VECTOR_CLEANROOM.md`에 근거를 기록하십시오.

## STEP 3. 기능 명세

`docs/VECTOR_SPEC.md`를 작성하십시오.

각 기능에 다음 항목을 기록하십시오.

- ID
- 기능명
- 설명
- 우선순위
- 입력
- 출력
- 완료 기준
- 테스트 ID
- 상태

## STEP 4. 샘플 파일

`samples/vector/`를 검사하십시오.

없으면 공개 SVG 규격에 맞게 시험 파일을 생성하십시오.

필수 샘플:
- 직선
- 베지어 곡선
- 기본 도형
- 복합 패스
- 그라디언트
- 클리핑 마스크
- 한글 문자
- 영문 문자
- 중첩 그룹
- 회전된 객체
- 외부 이미지
- 손상된 SVG
- 위험 요소가 포함된 SVG
- 지원하지 않는 SVG 속성

## STEP 5. UI 명세

`docs/VECTOR_UI_SPEC.md`를 작성하십시오.

도구, 메뉴, 패널, 단축키, 컨텍스트 메뉴를 정의하십시오.

기존 STULOOMA 화면과 통합하는 방법을 포함하십시오.

## STEP 6. 아키텍처

VectorDocument와 SceneGraph 데이터 구조를 확정하십시오.

기존 Command Manager, History Manager, Project Manager 연결 지점을 정의하십시오.

## STEP 7. 병렬 구현

가능하면 독립적인 서브에이전트를 활용하십시오.

**에이전트 A: Geometry**
- 베지어
- 경로
- Boolean
- 복합 패스
- 단위 테스트

**에이전트 B: Vector UI**
- 작업 공간
- 도구
- 선택
- 앵커 편집
- 패널

**에이전트 C: File**
- SVG 파싱
- SVG 출력
- Round-trip
- 보안 검증

**에이전트 D: 3D Integration**
- 벡터 텍스처 합성
- UV 연결
- 실시간 갱신
- 프로젝트 데이터 연결

**에이전트 E: QA**
- 자동 테스트
- UI 검증
- 성능 검사
- 기존 STULOOMA 회귀 테스트
- 배포 검증

서브에이전트 기능이 지원되지 않으면 같은 구분으로 순차 개발하십시오.

각 에이전트는 가능한 경우 서로 독립적인 파일을 수정하게 하십시오.

## STEP 8. 기능 통합

모듈 간 실제 데이터 연결을 구현하십시오.

2D 벡터 편집 결과가 3D 의류에 적용되는 전체 과정을 확인하십시오.

## STEP 9. 자동 테스트

VECTOR_SPEC.md의 완료 기준을 테스트에 연결하십시오.

실패한 기능은 원인을 수정한 뒤 다시 테스트하십시오.

실패 테스트를 삭제하거나 무단으로 건너뛰지 마십시오.

## STEP 10. UI 검증

앱을 직접 실행하여 실제 클릭과 입력으로 테스트하십시오.

아트보드에서 도형을 만들고, 합치고, 문자로 변경하고, 3D 의류에 적용하십시오.

## STEP 11. 배포

기존 STULOOMA 빌드 시스템을 이용하십시오.

Electron 환경과 기존 패키징 설정을 유지하십시오.

실제 개발 환경에서 패키징이 가능하다면 새 버전을 빌드하십시오.

## STEP 12. 최종 보고

완료 기능, 미구현 기능, 테스트 결과 및 시연 순서를 보고하십시오.

# 36. 완료 기준

기능은 다음 조건을 만족해야 완료로 인정하십시오.

1. 실제 소스코드 구현
2. 실제 UI 조작 가능
3. 데이터 변경
4. 렌더링 결과 반영
5. Undo/Redo 작동
6. 저장 및 복원
7. 오류 처리
8. 자동 테스트 통과
9. 기존 STULOOMA 기능 유지
10. 문서와 구현의 일치

다음 상태는 완료가 아닙니다.

- 버튼만 존재

- SVG를 이미지처럼 표시할 뿐 편집 불가

- 저장 후 편집 데이터 손실
- 3D 의류와 연결되지 않음
- 테스트를 실행하지 않음

# 37. 실제 사용 시연

최종 프로그램에서 다음 시나리오를 수행하십시오.

## 0:00~0:30

STULOOMA 실행
→ 기존 프로젝트 열기
→ Vector Studio 이동

## 0:30~1:00

사각형과 원 생성
→ 색상 변경
→ 도형 선택

## 1:00~1:30

원형으로 사각형 일부 빼기
→ 새 벡터 도형 생성
→ 앵커포인트 편집

## 1:30~2:00

STULOOMA 로고 또는 간단한 선수 번호 생성
→ 디자인 크기 및 위치 설정

## 2:00~2:30

완성한 벡터를 의류 앞판에 적용
→ 3D 화면 회전
→ 디자인 변경 즉시 반영 확인

## 2:30~3:00

프로젝트 저장
→ 다시 열기
→ 벡터 편집 상태 확인
→ SVG 및 목업 이미지 출력

모든 작업은 실제 구현된 기능만 사용하십시오.

기존 STULOOMA의 3D 모델, UV, 프로젝트 파일, 저장 기능이 손상되지 않아야 합니다.
