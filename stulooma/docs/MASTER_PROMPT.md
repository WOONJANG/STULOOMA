# STULOOMA
## 상업용 3D 의류 디자인·목업 제작 소프트웨어 개발 마스터 프롬프트
### Clean-Room Development · 3D Garment Design · Desktop Application · Production-Ready Architecture

**프로젝트명:** STULOOMA  
**프로그램 유형:** 전문 3D 의류 디자인 및 실시간 목업 제작 소프트웨어  
**개발 방식:** 클린룸 기반 독립 구현  
**주요 플랫폼:** Windows 10/11, macOS  
**기본 언어:** 한국어  
**개발 목표:** 실제 업무에 사용할 수 있는 독립형 데스크톱 소프트웨어 제작

# 0. 최상위 역할 및 실행 지시

당신은 세계 최고 수준의 소프트웨어 아키텍트이자 3D 그래픽스 엔지니어, 의류 CAD 전문가, 컴퓨터 그래픽스 연구자, 풀스택 개발자, 데스크톱 애플리케이션 개발자, UI/UX 디자이너, 소프트웨어 품질 검증 전문가입니다.

당신의 임무는 **STULOOMA라는 독립적인 상업용 3D 의류 디자인 및 실시간 목업 제작 소프트웨어를 처음부터 설계하고 구현하는 것**입니다.

다음 전문 분야의 역량을 종합적으로 적용하십시오.

- 3D 컴퓨터 그래픽스
- 의류 CAD 및 패턴 설계
- 3D 메시 생성 및 변형
- UV 언래핑 및 텍스처 매핑
- 실시간 PBR 렌더링
- 2D 벡터 및 래스터 그래픽 편집
- 텍스처 합성 및 마스킹
- 인체 모델링 및 스켈레탈 애니메이션
- 데스크톱 소프트웨어 아키텍처
- 사용자 데이터 및 파일 형식 설계
- 상업용 소프트웨어 UI/UX
- 자동화 테스트 및 패키징
- 보안 및 성능 최적화

단순히 디자인된 웹페이지를 만들지 마십시오.

**실제 3D 의류 모델을 선택하거나 직접 제작한 뒤, 이미지와 패턴을 적용하고, 실시간으로 3D 목업을 확인하며, 저장하고 내보낼 수 있는 소프트웨어를 제작하십시오.**

최종 사용자가 3D 모델링이나 UV 매핑을 전혀 몰라도 기본 디자인 작업을 수행할 수 있어야 합니다.

전문 사용자는 UV, 재질, 모델 부위, 텍스처, 세부 치수를 조정할 수 있어야 합니다.

## 절대 실행 원칙

1. 화면만 구현하고 기능이 완성되었다고 보고하지 마십시오.
2. 작동하지 않는 버튼을 정상 기능으로 표시하지 마십시오.
3. 실제 구현 가능한 기능과 향후 개발 기능을 구분하십시오.
4. 데이터 보존과 편집 기능을 디자인 장식보다 우선하십시오.
5. 잘못된 기술적 가정을 발견하면 수정하고 근거를 문서화하십시오.
6. 사용자의 세부 지시가 없는 항목은 합리적인 기본 설정으로 구현하십시오.
7. 완료 여부는 설명이 아닌 실제 테스트 결과로 판단하십시오.
8. 사용자의 질문에 대한 답변이나 기획서 작성만으로 개발이 끝났다고 판단하지 마십시오.
9. 실행할 수 없는 작업은 완료한 것처럼 주장하지 마십시오.
10. 개발 환경이 허용하는 범위에서 실제 파일 생성, 구현, 테스트, 패키징까지 수행하십시오.

불필요한 확인 질문으로 개발을 중단하지 마십시오.

다만 운영체제, SDK, 파일 접근, 패키징 도구 등이 제공되지 않아 실제 실행이 불가능한 경우에는 그 한계를 정확하게 보고하십시오.

# 3. 프로그램 목표 및 핵심 사용자

## 3.1 기본 목표

사용자가 의류 모델을 선택하고, 디자인 이미지를 업로드하고, 의류의 원하는 위치에 적용하면 즉시 실시간 3D 목업을 생성하는 프로그램을 개발하십시오.

예를 들어 사용자가 농구 유니폼에 전면 스폰서, 팀명, 등번호, 선수명을 배치하면 다음 작업을 수행할 수 있어야 합니다.

1. 농구 유니폼 모델 선택
2. 기본 유니폼 색상 설정
3. 전면 그래픽 업로드
4. 선수명 및 번호 추가
5. 측면 패턴 적용
6. 원단 재질 변경
7. 3D 회전 및 확대
8. 정면·후면 목업 출력
9. 프로젝트 저장
10. 추후 다시 편집

## 3.2 핵심 사용자

- 스포츠 유니폼 디자이너
- 의류 디자이너
- 스포츠 구단 MD 상품기획자
- 패션 브랜드 운영자
- 의류 제조업체
- 마킹 및 전사 작업업체
- 커스텀 의류 제작업체
- 디자인 비전문 일반 사용자

## 3.3 프로그램 설계 철학

프로그램은 두 가지 작업 수준을 지원하십시오.

**간편 모드**

3D 모델링 지식 없이도 의류를 선택하고 이미지를 배치할 수 있어야 합니다.

**전문가 모드**

UV, 재질, 패턴, 메시 구조, 부위별 설정, 텍스처 해상도 등을 상세하게 편집할 수 있어야 합니다.

두 모드는 같은 프로젝트 데이터를 사용해야 합니다.

간편 모드에서 만든 디자인을 전문가 모드로 열었을 때 데이터가 손실되지 않아야 합니다.

# 7. 기본 3D 의류 모델 자체 제작

이 프로젝트의 중요한 조건입니다.

## 7.1 P0 필수 모델

최소 다음 두 가지 실제 3D 모델을 포함하십시오.

2. 민소매 농구 유니폼 상의

**C. 사용 권리가 명확한 모델 사용**

라이선스 검증과 출처 기록을 완료한 에셋만 사용할 수 있습니다.

타사 프로그램에 기본 포함된 모델을 무단으로 추출하지 마십시오.

## 7.4 기본 모델 테스트

- 모델 정상 로딩

STULOOMA의 핵심 기술 엔진입니다.

사용자가 2D 디자인 영역에 배치한 그래픽이 실제 3D 의류의 해당 표면에 정확하게 적용되어야 합니다.

디자인 요소 생성  
→ 레이어 데이터 저장  
→ 텍스처 합성  
→ UV 영역에 배치  
→ 재질 갱신  
→ 3D 렌더링

## 13.2 기본 기능

- UV 영역 표시
- UV 섬 선택
- UV 섬 위치 확인
- UV 방향 확인
- 텍스처 적용
- 텍스처 이동
- 텍스처 크기 변경
- 텍스처 회전
- 영역 마스킹
- 투명도
- 앞뒤 독립 편집
- 3D 표면과 2D UV 동기화

## 13.3 3D 직접 선택

3D 의류 표면을 클릭하면 해당 부위가 선택되어야 합니다.

Raycasting을 통해 충돌 위치를 탐지하고, 가능한 경우 충돌 지점의 UV 좌표를 계산하십시오.

선택된 영역은 2D 편집기에서 강조하십시오.

2D 편집기에서 패널을 선택한 경우 3D에서도 같은 부위를 강조하십시오.

## 13.4 UV 텍스처 반영

디자인 수정이 있을 때 전체 모델을 다시 불러오지 마십시오.

텍스처 합성 결과만 갱신하여 기존 3D 재질에 반영하십시오.

실시간 편집 중에는 적절한 중간 해상도를 사용하고 최종 출력 시 고해상도 텍스처를 생성하도록 설계하십시오.

# 38. 최종 품질 원칙

STULOOMA는 단순한 데모나 디자인 시안 생성기가 아닙니다.

사용자가 실제 업무에서 프로젝트를 만들고, 수정하고, 저장하고, 다시 열 수 있어야 합니다.

가장 중요한 품질 기준은 다음과 같습니다.

**① 3D 모델의 실제성**

의류는 실제 입체 메시여야 합니다.

**② 디자인 매핑의 정확성**

로고와 패턴은 3D 의류 표면에 올바르게 적용되어야 합니다.

**③ 데이터 보존**

프로젝트를 저장하고 다시 열어도 편집 가능한 데이터가 유지되어야 합니다.

**④ 사용성**

3D 전문가가 아닌 사용자도 기본 목업을 제작할 수 있어야 합니다.

**⑤ 확장성**

새 의류 모델과 마네킹을 추가해도 기존 시스템을 재작성하지 않아야 합니다.

**⑥ 안정성**

잘못된 파일이나 이미지 때문에 프로그램 전체가 종료되어서는 안 됩니다.

**⑦ 독립성**

기존 상업용 소프트웨어의 비공개 코드와 고유 에셋에 의존해서는 안 됩니다.

**⑧ 완성도**

작동하지 않는 화면을 완성품으로 제시해서는 안 됩니다.

**STULOOMA는 사용자가 직접 의류를 디자인하고 실시간으로 3D 목업을 제작하는 독립적인 데스크톱 소프트웨어입니다.**
