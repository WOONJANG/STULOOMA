# Vector Studio 남은 기능·검증 한계

0.3.0의 벡터 생성·펜/앵커 편집·Boolean·한글 윤곽선·앞판 적용·저장/재열기·안전한 SVG 교환은 실제 검사로 확인했다. 이 목록은 그 결과와 별개로 남아 있는 기능·검증 범위를 명시한다. 전문 상용 벡터 제품 전체와 동등하거나 모든 요구 조합을 검증했다는 뜻이 아니다.

## 호환성·정밀도

- 원본 SVG byte는 프로젝트에 보관하지 않는다. 경고된 미지원 효과/메타데이터는 내보낸 SVG에서 복원할 수 없으므로 원본 파일을 따로 보관해야 한다.
- SVG 전체 사양, HTML foreignObject, animation, 외부 CSS·자원·폰트, 필터, 복잡한 SVG layout는 완전 지원 범위가 아니다. 안전상 거부와 지원 손실 경고를 사용자에게 알린다.
- AI의 비공개 편집 데이터·완전왕복과 PDF 벡터 입력은 지원하지 않는다. 공개 PDF 출력도 실제 구현/시험 전에는 사용 가능으로 표시하지 않는다.
- Boolean의 곡선은 문서 좌표 기본 0.25px tolerance의 폴리라인 근사를 거친다. 원래 cubic 제어점을 해석적으로 보존하는 연산이 아니다. 극소/퇴화/자기교차/매우 복잡한 경로는 추가 검증이 필요하다.
- 자기교차·되돌림 경로, 열린 경로, 허용 복잡도를 넘는 Boolean은 설명과 함께 거부하고 원본을 보존한다. 거부한 입력을 시각적으로 겹쳐 놓고 연산 성공으로 표시하지 않는다.
- v2 프로젝트는 새 앱에서 v1과 함께 읽는다. 이전 0.2.0 앱은 v2를 안전 거부한다. v2에서 원본 vector 데이터를 제거하는 하향 저장은 제공하지 않는다.
- 정확한 문자 외곽선은 번들 정적 `STULOOMA Noto Sans KR` Regular 400에 한정한다. 다른 font/weight·없는 글리프는 오류이며 시스템 폰트의 외곽선을 임의 추출하지 않는다.
- manifest 2MiB와 ZIP64MiB 제한이 유지되므로 매우 큰 vector 문서는 객체별 이론 한도보다 먼저 저장 한도에 도달할 수 있다.
- 벡터 편집 명령은 UTF-8 manifest 한도를 반영 전에 검사한다. SVG 입력 한도 안에 들어오는 파일도 프로젝트 저장 한도나 정규화 객체 한도를 넘으면 가져오기를 거부할 수 있다.
- 클리핑 경로와 불투명도 마스크는 서로 다르다. 내부 `maskId`의 저장·Canvas 알파·SVG 출력은 지원하지만 마스크 작성 UI는 없고 SVG 불투명도 마스크 가져오기는 경고 후 생략한다. 해당 SVG의 마스크 왕복 보존을 보장하지 않는다.
- 아트보드 단위는 표시 메타데이터이고 실제 좌표는 CSS px, 96px/inch다. mm/cm 표시를 선택해도 제작 치수 보정이나 CMYK 출력으로 바뀌지 않는다.

## 후속 전문 기능

P1 중 아직 제공하지 않는 기능: 패스 위 문자·영역 문자·아치 문자, 지원 밖 폰트/weight의 정확한 외곽선, 획 외곽선 확장, 아트보드 일괄 출력, 균등 분포·기준 개체 지정 정렬, PDF. 현재 여섯 방향 정렬과 다중 아트보드 작성/저장은 있으며 위의 고급 기능과 구분한다. 단순 stroke를 외곽선으로, PNG를 문자외곽선으로 표기하지 않는다.

P2: Image Trace, 경로 단순화·오프셋, 자유변형, 고급 패턴, 비파괴 Boolean, 복잡 SVG, 사용자 자동화·CSV 선수번호 일괄 생성.

P3: 정확한 CMYK/ICC·인쇄 분판·실물 생산용 마킹/패턴/CAD. 현재 RGB 출력과 의류 UV 캔버스의 문서 단위는 생산 치수/인쇄 색상 보정을 보장하지 않는다.

## 플랫폼·검사

- Linux/Chromium 클라우드와 Xvfb/Electron 시험 결과만 실제 실행으로 기록한다. Windows·macOS GUI/실제 OS IME·고DPI/펜/태블릿·접근성 보조도구 검증은 별도다.
- Windows ZIP 생성·헤더/CRC/hash검사와 코드 서명·SmartScreen 평판·Windows 실행 성공은 다른 단계다.
- 벡터 UI의 한글 Unicode 입력·입력 필드 내 편집키는 자동시험했다. 기존 workspace의 합성 조합 이벤트 가드 시험과 이 결과를 실제 운영체제 IME 입력기의 전 과정으로 확대 해석하지 않는다.
- 앞판/뒷판 WebGL 갱신, 잠긴 상위 그룹·경로, 그룹·클립·아트보드 복제는 실제 UI 검사했다. 소매의 전체 벡터 출력, 모든 잠금·숨김·영역 선택·그룹·아트보드 조합, 2D/3D Undo의 연속 프레임 픽셀 비교는 추가 QA 범위다. 기존 UV/부위 단위 회귀와 구분한다.
- 대형문서·저사양GPU·장시간사용·고해상도 메모리·복잡 clip/gradient의 성능 수치는 계측 전 추정하지 않는다.
- 렌더 캐시의 16메가픽셀 누적 한도와 제거 동작은 시험했지만 프로세스 전체 메모리 상한이나 모든 SVG의 렌더 성능을 보장하는 수치는 아니다.
- 기존 의류 목업은 정적 3D 시각화다. 착의물리·생산패턴·상용출시인증은 이번 벡터 모듈 추가로 구현되지 않는다.

최종 단위/보안 147개, 전체 Chromium 24개, Electron 4개가 통과했다. Linux 패키지에서 같은 Electron 4개를 재실행했고 ZIP·코드/글꼴/고지 무결성을 확인했다. 이 검사 수를 플랫폼 인증이나 모든 편집 조합의 보장으로 확대하지 않는다. 실제 로그는 [VECTOR_RESULTS.md](VECTOR_RESULTS.md)를 따른다.
