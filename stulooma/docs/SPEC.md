## P0의 범위 경계

기본 모델은 독립 제작한 반팔과 민소매 농구 상의 두 종류다. 사용자 GLB는 제약이 있는 2.0 자체 포함 파일만 받으며 일반 glTF, OBJ, FBX를 지원 형식으로 표시하지 않는다. 자동 UV 생성, 임의 삼각형/UV 영역 페인팅, 모든 glTF 확장, 물리 착의, 마네킹, 봉제용 CAD와 패턴 제작은 현재 완료 항목이 아니다. 상세 차이는 [GAPS.md](GAPS.md)에 기록한다.

외부 모델의 이름 기반 mesh 영역 지정은 앞판/뒷판을 임의로 자동 추론하는 기능이 아니다. 단일 mesh에 앞뒤가 섞인 모델은 외부 도구에서 영역을 나누어야 한다. 모델 검사 성공은 원본 저작권 또는 생산 적합성 확인을 뜻하지 않는다.

## 인수 흐름

반팔 선택 → 검정 앞판 → 투명 PNG 업로드 → 왼쪽 가슴 이동·크기·회전 → 3D 360° 확인 → 정면 PNG → `.stulooma` 저장 → 종료/재실행 → 열기 → 위치·앞뒤·색상·재질·카메라 확인 → 재편집·재저장. 농구 상의와 사용자 GLB에도 같은 데이터 보존 흐름을 적용한다. 후드티 시나리오는 실제 모델이 추가되기 전 실행 완료로 보고하지 않는다.
