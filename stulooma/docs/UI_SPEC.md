# 화면·상호작용 명세

STULOOMA는 한국어 데스크톱 의류 목업 편집기다. Graphite 배경, mint 선택 강조와 일관된 숫자 입력을 사용한다. 전문 편집 도구의 익숙한 작업 관례를 적용하되 경쟁 제품의 로고·아이콘·고유 화면을 복제하지 않는다. 화면 개선은 상용 인증이나 모든 플랫폼 검증 완료를 뜻하지 않는다. 실행되지 않는 기능을 정상 버튼으로 표시하지 않는다.

## 작업 공간

| 영역 | 역할 | 실제 연결 |
|---|---|---|
| 상단 앱·문서 영역 | STULOOMA, 프로젝트명, 저장 상태, 파일/편집/디자인/보기/도움말 메뉴, 명령 검색 | 같은 StudioCommand 목록과 dispatcher |
| 툴바 | 새 문서·열기·저장, Undo/Redo, PNG·텍스트, 패널 표시, 간편/전문가, 출력 | 애플리케이션 명령 및 문서 설정 |
| 왼쪽 라이브러리 | 실제 반팔·농구 모델, 등록한 GLB | 새 garment 문서 / model.import |
| 중앙 작업 공간 | 3D/분할/2D 보기, 크기 조절 경계, 활성 부위 | 로컬 작업 공간 설정과 문서 선택 |
| 2D 디자인 | 레이어 선택·이동·크기·회전, 확대·이동·그리드·스냅 | artwork.update, 캔버스 표시 상태 |
| 3D 목업 | 실제 PBR 의류·회전·확대·부위 클릭 | 카메라와 activeRegion |
| 오른쪽 속성 | 선택 레이어, 정렬·숫자·텍스트, 부위 색·재질, 표시·잠금·순서 | typed 문서 명령 |
| 편집 기록 탭 | 이전 문서 스냅샷, 현재 상태, Undo/Redo | 최대 100개 문서 history |
| 상태 영역 | 미저장·로컬 복구·최근 작업·처리 중·오류 | 실제 상태와 진단 결과 |

라이브러리 너비는 176–320px, 속성 패널은 264–400px 범위에서 조절한다. 경계 드래그 또는 초점 후 좌우 방향키 8px, Shift+방향키 32px, Home/End 최소/최대, 두 번 클릭 기본 너비를 지원한다. 분할 경계는 35–75% 범위에서 드래그하거나 좌우 방향키로 3%씩 이동한다. 보기 메뉴나 툴바에서 패널을 각각 접고 펼친다. Ctrl/Command+역슬래시는 하나라도 보이면 둘 다 숨기고, 둘 다 숨겨져 있으면 둘 다 표시한다.

보기 모드·분할 비율·패널 너비·표시 여부는 localStorage의 `stulooma.workspace.v1`에 보관한다. 이는 프로젝트 내용이나 Undo 대상이 아니다. 작업 공간 초기화는 이 항목을 기본값으로 되돌린다. 그리드·스냅은 별도 로컬 설정이며 캔버스 확대·이동은 화면 상태다. 간편/전문가 모드는 같은 문서의 `settings.mode`이며 모드 전환으로 데이터를 삭제하지 않는다. 작은 화면에서는 패널 접기·스크롤·캔버스 세로 배치를 사용한다. 중앙 작업을 이미지로 대체하지 않는다.

## 기본 흐름과 파일 놓기

1. 반팔 또는 농구 상의를 선택한다. 문서 교체 전 미저장 변경을 확인한다.
2. 앞판 또는 뒷판을 고르고 PNG나 텍스트를 추가한다.
3. 2D 이동·크기·회전 핸들 또는 속성 숫자·정렬을 사용한다. 같은 레이어가 3D에 반영된다.
4. 3D 드래그 회전·휠 확대·시점 버튼으로 표면 부착을 확인한다.
5. 편집 가능한 프로젝트를 저장하고 PNG/JPG 이미지 또는 GLB를 출력한다. 재열기 시 원본 자원과 레이어가 복원된다.

작업 화면에 PNG, GLB, `.stulooma` 파일을 한 개씩 놓을 수도 있다. PNG는 활성 부위에 추가한다. GLB는 구조·UV 검사 후 메시별 FRONT/BACK 등 부위 지정 대화상자를 거쳐 등록한다. 프로젝트는 검증 후 미저장 교체 확인을 거친다. 여러 파일·미지원 형식·손상 파일은 오류를 표시하고 기존 문서를 보존한다. 확장자 분류 후에도 실제 헤더·구조·한도 검사를 수행한다. UV 없는 모델은 등록하지 않고 외부 도구에서 UV를 만든 뒤 다시 가져오도록 안내한다.

## 메뉴·선택·기록

메뉴는 실제 명령만 노출한다. 방향키·Home/End로 이동하고 Enter로 실행하며 Escape로 닫는다. 명령 검색은 한글 이름·영문 키워드·단축키를 지원하고 위/아래 방향키와 Enter로 실행한다. 실행 불가 항목은 비활성화한다. 검색 대화상자는 초점을 포함하고 닫을 때 이전 초점으로 복귀한다. 레이어 또는 2D 영역의 오른쪽 클릭은 편집/추가/정렬 문맥 메뉴를 연다.

레이어 선택 시 해당 부위가 활성화된다. 두 번 클릭·F2·이름 바꾸기 명령으로 한글 이름을 변경한다. 복사/붙여넣기는 앱 내부 레이어 클립보드다. 원본 PNG를 보존하며 다른 부위·새 프로젝트에도 붙여넣을 수 있다. 사본은 새 ID·오프셋·잠금 해제를 가진다. OS 클립보드나 외부 앱 데이터 교환을 지원한다고 표시하지 않는다.

잠긴 레이어는 이동·크기·회전·텍스트·정렬·삭제·순서 변경을 막는다. 이름·표시 여부·잠금 해제는 가능하며 복사/복제는 원본을 바꾸지 않는다. 순서 이동은 같은 부위의 레이어끼리만 수행한다. 정렬은 회전을 반영한 경계 상자를 활성 부위의 단위 캔버스에 맞춘다. 다중 선택·그룹 편집은 제공하지 않는다.

편집 기록의 이전 상태를 클릭하면 해당 지점까지 Undo를 반복한다. 현재 상태와 Redo 가능한 단계 수를 표시한다. 영구 버전 관리나 작업별 명명 로그가 아니며 문서 교체 시 비운다. 새 편집은 Redo를 지운다. 같은 값·잘못된 대상·변화 없는 그룹은 새 기록이나 미저장 표시를 만들지 않는다. 저장한 내용으로 Undo/Redo하면 저장 상태도 그 내용에 맞춰 복원한다.

## 2D 캔버스

| 조작 | 동작 |
|---|---|
| 레이어 드래그 / 모서리 / 위쪽 핸들 | 이동 / 비율 유지 크기 / 회전. 한 드래그는 한 Undo |
| Shift+회전 | 15° 단위 회전 |
| Space+드래그 또는 마우스 중간 버튼 | 화면 이동; 문서 transform 불변 |
| 일반 휠 / Shift+휠 | 화면 이동 / 가로 화면 이동 |
| Ctrl/Command+휠 | 포인터 기준 확대·축소, 25–400% |
| + 또는 = / - | 캔버스 초점에서 확대 / 축소 |
| Ctrl/Command+0 | 캔버스 초점에서 100% 맞춤과 이동 초기화 |
| G / S | 캔버스 초점에서 그리드 / 스냅 전환 |
| Alt+이동 | 스냅 일시 해제 |
| 방향키 / Shift+방향키 | 선택 레이어를 정규화 좌표 0.001 / 0.01씩 이동 |

스냅은 캔버스 가장자리·중심선과 활성 부위의 다른 보이는 레이어의 회전 경계·중심을 기준으로 한다. 근접 기준은 화면 약 6px이며 맞춰진 축에 스마트 가이드를 표시한다. 그리드·가이드·확대·이동은 출력 텍스처나 프로젝트 transform에 포함하지 않는다. 새 프로젝트는 확대·이동을 초기화한다. 그리드·스냅 설정은 `stulooma.canvas.grid` / `stulooma.canvas.snap`에 별도로 보관한다.

## 전역 키보드와 한국어

| 입력 | 명령 / 동작 |
|---|---|
| Ctrl/Command+N / O | 새 프로젝트 / 열기 |
| Ctrl/Command+S / Shift+S | 저장 / 다른 이름으로 저장 |
| Ctrl/Command+Shift+E | 내보내기 대화상자 |
| Ctrl/Command+Z | 실행 취소 |
| Ctrl/Command+Shift+Z 또는 Ctrl/Command+Y | 다시 실행 |
| Ctrl/Command+C / V / D | 레이어 복사 / 붙여넣기 / 복제 |
| Ctrl/Command+K | 명령 검색 |
| Ctrl/Command+역슬래시 | 양쪽 패널 표시 전환 |
| F2 / F1 / F | 레이어 이름 / 사용 가이드 / 3D 전체 보기 |
| Delete 또는 Backspace / Escape | 선택 레이어 삭제 / 선택 해제 |
| 방향키 / Shift+방향키 | 선택 레이어 0.1% / 1% 이동; separator·탭 탐색에서는 실행하지 않음 |

IME 조합 중(`isComposing` 또는 keyCode 229) 전역 명령을 실행하지 않는다. 메뉴나 대화상자가 열린 동안도 전역 편집을 막는다. input/textarea/select/contenteditable에서는 기본 복사·붙여넣기·Undo·삭제·방향키를 보존한다. 예외는 Ctrl/Command+S와 K이며, 입력 초점을 먼저 벗어나 값을 커밋한 뒤 저장 또는 검색한다. 실제 OS IME 입력 검증은 자동 문자열 삽입과 구분한다.

숫자 입력은 미완성 소수·음수를 로컬 초안으로 유지하고 Blur/Enter에서 유한 숫자만 커밋한다. Escape는 현재 문서 값으로 되돌린다. 도메인 명령은 유효 범위로 제한하며 NaN·무한대·잘못된 색·레이어 ID 변경을 적용하지 않는다. 사용자 제목과 실제 저장명은 구분하고 파일명을 별도 정규화한다.

## 저장·오류·현재 범위

Electron의 첫 저장·다른 이름으로 저장은 네이티브 대화상자를 연다. 네이티브 열기/저장에서 승인한 대상은 현재 창 세션의 불투명 토큰으로 연결되어 이후 저장은 같은 파일을 원자적으로 교체한다. 경로는 renderer나 문서에 노출·저장하지 않는다. 새 문서·드롭 열기·복구에는 기존 대상 권한을 상속하지 않는다. 브라우저의 저장·다른 이름으로 저장은 모두 새 파일 다운로드 요청이며 기존 파일 덮어쓰기를 약속하지 않는다.

파싱 실패·UV 없음·한도 초과·저장 취소·출력 실패를 구분한다. 실패한 열기는 기존 문서를 보존하고 취소를 성공으로 표시하지 않는다. 저장 중 새 변경은 미저장으로 남는다. 파일 작업은 중복 실행을 막는다. 로컬 복구는 수동 저장을 대체하지 않는다.

PNG 가져오기와 텍스트, PNG/JPG/GLB 출력만 실제 연결된 범위다. SVG/JPG/WEBP 가져오기, 패널 그리기, 자동 UV, 치수 CAD, 봉제·착의 물리, 마네킹, 다중 선택·그룹, 일괄 출력, 최근 파일 영구 목록은 미구현이다. 구체적인 명령·조건은 [COMMANDS.md](COMMANDS.md), 검증은 [TEST_PLAN.md](TEST_PLAN.md)를 따른다.
