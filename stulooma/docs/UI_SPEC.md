# 화면·상호작용 명세

STULOOMA는 한국어 데스크톱 편집 화면을 기본으로 한다. 따뜻한 graphite 배경, teal 선택 강조, cream 기본 의류, 일관된 숫자 입력과 높은 작업 정보 밀도를 사용한다. 경쟁 제품의 로고·아이콘·고유 UI를 재사용하지 않는다. 실행되지 않는 기능을 정상 버튼으로 표시하지 않는다.

| 영역 | 역할 | 명령·데이터 연결 |
|---|---|---|
| 상단 | STULOOMA, 프로젝트명, 새로 만들기/열기/저장, Undo/Redo, 출력 | `project.*`, `edit.*`, `export.*` |
| 왼쪽 라이브러리 | 실제 반팔·농구 모델 선택, 사용자 GLB 가져오기 | 새 garment 문서 / `model.import` |
| 2D 디자인 | 활성 부위의 원본 레이어 이동·변형·선택 | `artwork.add/update`, region 선택 |
| 3D 목업 | 실제 PBR 의류·회전·확대·부위 클릭 | 카메라와 activeRegion |
| 오른쪽 속성 | 앞뒤 부위, 색상, roughness, 위치·크기·회전, 레이어 | `material.update`, `artwork.update`, `layer.reorder` |
| 상태 영역 | 저장 상태·선택·처리 중·오류·모델 검사 | dirty, 현재 작업, 실제 진단 결과 |

최소 화면에서는 패널을 접거나 스크롤로 접근할 수 있게 한다. 중앙 작업을 이미지로 대체하지 않는다. 간편/전문가 모드가 표시되는 경우 동일 문서를 사용하며 모드 전환은 데이터를 버리지 않는다. 모델 제작·마네킹·물리 시뮬레이션 화면은 미구현 기능으로 남긴다.

## 기본 작업 흐름

1. 반팔 또는 농구 상의를 선택한다. 모델 변경으로 디자인이 초기화될 수 있다면 미저장 변경을 확인한다.
2. 앞판 또는 뒷판을 고른다. 색상을 바꾸고 PNG를 가져온다.
3. 2D 캔버스에서 로고를 선택·이동한다. 속성의 크기·각도·위치 변경이 같은 레이어에 반영된다.
4. 3D에서 드래그 회전, 휠 확대, 앞/뒤 시점 버튼으로 표면 부착을 확인한다.
5. PNG를 내보내고 프로젝트를 저장한다. 다시 열면 원본 이미지와 편집 가능한 레이어가 복원된다.

사용자 GLB: 파일 선택 → 구조·UV 검사 → mesh 이름을 확인하고 FRONT/BACK 등 부위 지정 → 등록 → 같은 디자인 편집. UV가 없으면 모델을 디자인 가능 상태로 등록하지 않고 외부 도구에서 UV를 만든 뒤 다시 가져오도록 안내한다.

## 키보드와 한국어

| 입력 | 명령 / 동작 |
|---|---|
| Ctrl/Command+N | `project.new` |
| Ctrl/Command+O | `project.open` |
| Ctrl/Command+S | `project.save` |
| Ctrl/Command+Shift+S | `project.saveAs` |
| Ctrl/Command+Z | `edit.undo` |
| Ctrl/Command+Shift+Z 또는 Ctrl+Y | `edit.redo` |
| Ctrl/Command+D | `edit.duplicate` |
| Delete / Backspace | 선택 레이어 삭제; 입력 요소에서는 텍스트 편집 |
| Esc | 선택 해제 |

IME composition 중 전역 단축키를 실행하지 않는다. input/textarea/contenteditable 안에서 삭제·복제·Undo가 전체 디자인을 잘못 변경하지 않게 한다. 한국어 텍스트는 조합이 완료된 값을 커밋하고 정상 round-trip을 확인한다. 사용자 파일명은 원본 제목과 별도로 안전한 저장명으로 제안한다.

## 오류와 저장 상태

파일 파싱 실패, UV 없음, 파일 한도 초과, 저장 취소, 내보내기 실패를 구분한다. 오류는 작업 영역에 한국어로 표시하고 기존 디자인을 보존한다. 저장 취소를 저장 성공으로 표시하지 않는다. 저장 중 발생한 새 변경은 미저장으로 남긴다. 처리 중에는 중복 import/export를 제한하고 상태를 표시한다.

## 현재 범위

PNG를 기본 지원한다. SVG/JPG/WEBP 가져오기, 패널 그리기, 자동 UV, 치수 CAD, 원단 라이브러리, 다중 시점 일괄 출력은 실제 구현과 검증 전 지원으로 표시하지 않는다. 텍스트·JPG/GLB 출력 등 P1 확장은 실제 연결된 항목만 제공한다. 각 버튼의 구체적 조건과 오류는 [COMMANDS.md](COMMANDS.md).
